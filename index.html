✨ 自動読み取りを使うには

クロード(Claude)という人工知能に登録すると、このボタンが使えるようになります。登録は無料です。

  • 📸 写真を撮ってボタンを押すだけで、回転数や当たり回数が欄に入る
  • ✍️ 小さい数字を打ち込む手間と、打ち間違いが減る
  • 🔍 読めなかった所は空欄のまま。勝手な数字は入れない
  • 💴 課金しなくても使えます。有料プランに入る必要はありません(無料のままだと、1日に使える回数に上限があります)
  1. アップストアで「Claude」と調べて、クロードのアプリを入れる
  2. アプリを開いて、メールアドレスなどで無料登録する(有料プランの案内が出ても、入らずに閉じてかまいません)
  3. このページのリンクを、もう一度開き直す
  4. 「写真の数字を読み取る」を押し、最初に出る確認で「許可」を押す

アプリを入れなくても、サファリで claude.ai に登録・ログインしてからこのリンクを開いても使えます。登録しなくても、撮影・手入力・記録はそのまま使えます。

データカウンターを正面から、数字がはっきり写るように撮ると読み取りやすいです。読めなかった所は空欄のままにします(当て推量では埋めません)。間違っていたら下の欄を押して直せます。

❓ 遊び方

使い方

  1. トップで「パチンコで使う」か「スロットで使う」を押す
  2. 「カメラで撮る」で、台のデータ画面を正面から撮る
  3. 「写真の数字を読み取る」を押すと、回転数や当たり回数が欄に入る(読めない所は空欄のまま)
  4. 違っていたら欄を押して直し、「この内容を記録する」を押す
  5. 帰ったら「収支管理」に使ったお金と戻ったお金を入れる。ランキングに反映されます
  6. 朝一は「朝一モード」で前日・前々日・液晶の3枚を撮る
